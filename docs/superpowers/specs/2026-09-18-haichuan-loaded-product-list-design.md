# 海川已装柜产品明细设计

## 目标

“已装柜”页面直接展示我方已审核通过的所有产品，不再展示批次 ID 或批次汇总。一个装柜批次包含多少条产品明细，页面就显示多少行。

管理员端和海川物流端共用同一套产品明细展示。

## 数据来源

页面继续读取现有 `haichuan_loading_batches` 及其 `items`，只选择状态为 `approved` 的批次，并在前端展开为产品明细行，不新增数据库表或迁移。

每一行使用管理员审核后的最终数据：

- 最终装柜件数：`approvedCartonCount`，旧数据为空时回退到 `requestedCartonCount`。
- 最终装柜数量：`approvedProductQuantity`，旧数据为空时回退到 `suggestedProductQuantity`。
- 最终 CBM：`approvedCbm`，旧数据为空时回退到 `suggestedCbm`。
- 装柜日期、确认时间和状态来自所属的已审核批次。

## 页面字段

表格按产品逐行显示以下统一字段：

1. 产品名称。
2. 内部编号。
3. SKU。
4. 装柜日期。
5. 最终装柜件数。
6. 最终装柜数量。
7. 最终 CBM。
8. 状态，固定显示“已装柜”。
9. 确认时间。
10. 备注，优先显示产品审核备注。

页面不再显示批次 ID、产品项数或批次合计。没有已装柜产品时显示“暂无已装柜产品”。

## 实现边界

- 只修改 `HaichuanWorkflowPage` 的已装柜展示数据与表格。
- 不修改装柜提交、管理员审核、库存冻结、库存扣减或海运在途写入逻辑。
- 不改变整柜和冠通流程。
- 同一 SKU 的不同采购记录继续分别显示，不合并，保留原装柜明细来源。

## 验收

- 一个已审核批次包含多条产品时，每条产品各显示一行。
- 不显示批次 ID 和批次汇总列。
- 页面显示管理员最终审核后的件数、数量和 CBM。
- 管理员端与海川物流端看到一致的已装柜产品明细。
- 当前测试记录显示为 5 件、65 个、0.065625 CBM。
- 空列表文案为“暂无已装柜产品”。
