# Bestby 缺货梳理分类设计

## 目标

以 `Bestby缺货梳理（2026.09.14）.xlsx` 为唯一主表来源，保留原文件不变，输出一个新的 Excel 工作簿。新工作簿应统一缺货原因分类，并在第一页展示各分类的产品数量。

## 输出结构

- 第一页为分类汇总，列出分类名称、产品数和总计。
- 第二页保留原表的全部明细、原备注、数值和现有视觉标记，并新增标准化的 `缺货分类` 列。
- 不覆盖或删除原备注，不修改源文件。

## 分类规则与优先级

分类按以下顺序判断，每个产品只计入一个分类：

1. `海运在途`：装柜日期和对应数量均已填写；多批次日期或数量仍计为一个产品。
2. `中国团队上新`：原备注明确包含中国团队上新、国内上新或等价表述。
3. `银豹没有SKU`：原备注明确表示银豹中没有 SKU。
4. `链接有问题`：原备注明确表示产品链接、图片链接或产品页面异常，需要修改。
5. `下架`：原备注明确表示产品已经下架、将下架或需要下架。
6. `银豹库存被修改为0`：原备注明确表示银豹库存被清零、修改成 0 或等价含义。
7. `其他`：空白、含义不明确、无法归入以上类别的记录，以及标红且没有订货的记录。

若一条备注同时命中多个非在途类别，按上述顺序采用第一个明确类别。标红本身不覆盖明确的其他分类；只有标红且没有订货、又无其他明确原因时归入 `其他`。

## 计数口径

- 产品数按明细行数统计，一行代表一个产品。
- 所有分类数量之和必须等于明细产品总数。
- 汇总表不重复计算多批次在途数量。

## 格式与验证

- 汇总页放在最左侧，使用简洁表格展示七类产品数和总计。
- 明细页延续原表格式；新增分类列使用清晰的表头，并保留原标红信息。
- 检查所有明细均有分类，分类总计与明细行数一致，并扫描明显公式错误。
- 导出后渲染汇总页和明细页关键区域，确认中文、列宽、换行和数字显示正常。
