# New Product Launch 一期设计

中国管理系统保存新品和到货结果。南非员工使用现有 BMS 账号查看新品并确认实际到货。BMS 后端调用中国系统 API，两个页面读取同一份状态。

## 页面与数据

- 中国系统新增独立菜单 **New Product Launch**，包含列表和新增表单。录入必填 SKU、产品名称、主图、实际 Live Store 和唛头名称（Shipping Mark）。列表展示这些字段及状态、确认人和确认时间，支持搜索和筛选。
- BMS 的 **New Product Arrivals** 默认展示待到货记录，可查看已确认记录。列表显示主图，列表及确认弹窗均展示 SKU、产品名称、店铺和唛头名称。
- SKU 以纯数字字符串保存和传输，保留前导零。数据库对「SKU + Live Store」设唯一约束，允许同一 SKU 在不同店铺各建一条记录。每条记录有稳定 ID，分别确认。
- 保存创建人、创建时间、记录版本及主图存储路径。初始状态为 Pending Arrival。确认后为 Received，保存 BMS 员工稳定 ID、姓名快照和服务端时间。
- 一期范围为到货登记和确认。正式开放销售状态、采购订单、海运批次和仓库入库均在范围之外。

## API 和确认

- `GET /api/v1/new-product-launches` 支持分页和状态筛选，返回列表字段、记录版本及主图短期签名地址。
- `POST /api/v1/new-product-launches/{id}/receive` 提交记录版本和员工身份。BMS 后端从登录会话取得员工 ID 和姓名，并使用服务端凭据访问中国 API。BMS 正式确认权限待定，联调使用指定测试账号。
- 数据库在版本匹配且状态为 Pending Arrival 时原子写入确认结果。同一版本重复提交返回 HTTP 200 和原确认结果。并发确认保留首个成功提交者和时间。版本过期返回 HTTP 409，BMS 刷新后由员工重新核对。
- BMS 提交时禁用确认按钮。超时后刷新确认状态，仍待确认时可重试。中国列表刷新时显示最新结果。

## 纠错

- 原录入人或中国系统管理员可通过专用操作纠正 SKU，重新校验同店唯一性，并记录修改前后值、操作人、时间和原因。普通编辑入口保护 SKU 及确认字段。
- 原录入人或管理员可填写原因撤销误确认。撤销将记录恢复为 Pending Arrival，清空当前确认字段，并在操作历史中保存原确认人和时间。撤销、历史写入和版本更新在同一事务完成。
- 撤销或修改影响核对的资料时递增版本，使旧请求失效。每个版本最多成功确认一次。重新确认写入新一轮员工和时间，保留历史。
