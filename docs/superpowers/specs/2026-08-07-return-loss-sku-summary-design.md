# 退货基础损失 SKU 汇总设计

## 目标

将“退货基础损失”当前的逐笔退货列表改为两级结构：先展示 SKU 汇总，再由每个 SKU 行内展开对应的退货订单明细。

## 汇总规则

- 使用当前页面内存中的退货明细按规范化 SKU 分组，不新增数据库存储。
- 每个 SKU 汇总退货数量、采购成本 ZAR、海运费、国内运费、送仓费、分摊 Total Fees、退货基础损失和退货额外损失。
- 产品名称取该 SKU 退货明细中第一个非空名称。
- 异常原因合并去重；没有异常时显示“正常”。
- 当前数据中只要存在非零退货额外损失，汇总表和订单明细都显示该列；全部为零时整列隐藏。

## 页面交互

- 点击“退货基础损失”卡片后显示 SKU 汇总表。
- 每个 SKU 汇总行提供“展开明细”按钮，并标明该 SKU 的退货订单数量。
- 展开后在当前 SKU 行下方显示原有逐笔退货订单字段，包括退货编号、原订单号、退货日期、各项成本、Total Fees 来源订单号及异常原因。
- 多个 SKU 可以同时展开，交互方式与销售利润 SKU 表一致。

## 范围

- 不修改退货基础损失和额外损失计算公式。
- 不修改 Supabase 表结构。
- 不修改 Excel 导出。

## 验证

- 同一 SKU 多笔退货正确汇总数量和金额。
- 展开后只显示该 SKU 的订单明细。
- 额外损失列按是否存在非零金额动态显示。
- 无异常时显示“正常”，异常信息不重复。
- TypeScript 与 Vite 生产构建通过。
