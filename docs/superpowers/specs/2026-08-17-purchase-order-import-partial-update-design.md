# 采购订单导入仅更新有值字段

## 问题

采购订单解析器会将空白单元格转换为空字符串、零或空值，整行合并时会错误清空原订单的内部编号、计划采购数量及其他资料。

## 设计

- 解析器同时返回订单数据和“原表格中实际有值的字段”列表。
- 非空单元格覆盖原订单；空白或缺少的列保留原值。
- 显式填写数字 `0` 视为有效值，可以将原字段更新为零。
- 内部编号、计划采购数量、实际采购数量、价格、运费、箱规、CBM 和文本资料统一使用该规则。
- 订单 ID、采购人、采购池、状态及物流工作流字段继续保留，不允许通过导入覆盖。
- 数量、价格或运费变化且表格未明确提供总金额时，自动重算总金额；总 CBM 按更新后的数量和单品 CBM 重算。
- 新增订单仍使用解析后的完整默认记录。

## 验证

- 仅填写部分列时，内部编号和计划采购数量保持不变。
- 显式填写 0 时能够更新为 0。
- 表格提供内部编号或计划采购数量时正常覆盖。
- 现有 SKU 匹配、单条更新、文件内去重和无匹配新增规则不变。
- TypeScript/Vite 生产构建通过。
