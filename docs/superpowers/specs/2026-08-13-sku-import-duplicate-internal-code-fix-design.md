# SKU 导入重复内部编号修复设计

## 问题

SKU 批量导入更新时，数据库返回 `23505`，违反唯一索引 `sku_items_internal_code_idx`。当前内部编号整理函数只为缺少编号的记录分配编号，没有处理不同记录携带相同内部编号的情况。

## 修复规则

- 数据库已有匹配 SKU 的内部编号优先保留，导入文件不能覆盖。
- 整理完整 SKU 列表时，每个有效五位内部编号只能分配给一条记录。
- 重复编号按稳定排序保留第一条，其余重复记录视为缺少编号并自动分配未使用的五位编号。
- 空编号、无效编号和重复编号使用相同的自动分配流程。
- 不删除 SKU，不改变 SKU、TSIN、产品名称、价格或 CBM 等业务字段。

## 数据流

1. 导入预览根据 SKU 等匹配已有云端记录。
2. 更新记录沿用云端记录的 ID 和内部编号。
3. 保存前合并本地与云端数据。
4. 内部编号整理函数对完整列表去重并补齐。
5. 完成整理后再批量 upsert，满足数据库唯一索引。

## 验证

- 两条记录使用相同内部编号时，最终编号互不重复。
- 已有编号的首条记录保持原编号。
- 空编号和重复编号获得新的可用五位编号。
- 同一输入多次整理结果稳定。
- TypeScript 与 Vite 生产构建通过。
