# 采购池日期与装货方式即时保存设计

## 问题

采购池逐行日期当前先在 `onChange` 中写入 React 草稿状态，再在 `onBlur` 中从草稿状态读取并保存。日期选择器的变更和失焦可能连续发生，保存函数会读取到更新前的草稿，导致第一次选择没有反应，需要重复点击。

## 设计

- 逐行装柜日期在 `onChange` 时立即保存。
- 保存函数直接接收事件中的当前值，不依赖尚未完成更新的 React 草稿状态。
- 装货方式下拉同样在选择后立即保存，避免相同的事件时序问题。
- 日期和装货方式不再额外使用 `onBlur` 保存，避免重复请求。
- 文本和数字输入继续采用现有失焦保存方式。
- 保存采购池快照和采购记录主表时继续使用同一份规范化记录。
- 保存失败时保留现有错误提示，由后续云端刷新恢复真实值。

## 验证

1. 日期保存函数可以直接使用本次输入值，不要求草稿状态已经更新。
2. 日期输入只触发一次保存路径。
3. 装货方式选择只触发一次保存路径。
4. 采购池整柜 / 冠通规则测试通过。
5. TypeScript 生产构建通过。
