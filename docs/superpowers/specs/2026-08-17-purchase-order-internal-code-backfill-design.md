# 我的采购订单内部编号自动补全

## 目标

修复历史通过表格导入的采购订单内部编号为空的问题，并确保页面加载后自动将匹配结果保存回数据库。

## 匹配与写入

- 仅处理当前采购人名下、内部编号为空且 SKU 不是空值或 `NEW` 的订单。
- 优先按“店铺 + 规范化 SKU”匹配 SKU 资料库；店铺无匹配时按规范化 SKU 回退匹配。
- 只有 SKU 资料库内部编号非空时才执行补全。
- 已有内部编号不覆盖；无法匹配的订单保持不变。
- 保存时仅改变订单的 `internalCode`，数量、金额、状态、采购池及物流字段全部保持原值。

## 页面行为

- 页面显示内部编号时同步使用 SKU 资料库回退值，云端保存完成前也能立即显示。
- 页面加载且订单、SKU 资料均可用后自动批量保存匹配结果。
- 同一批补全不会重复提交；成功后提示补全数量，失败时显示错误并允许刷新页面重试。

## 验证

- 验证店铺 + SKU 精确匹配、SKU 回退匹配、已有编号保护、NEW/空 SKU 跳过和无匹配跳过。
- 验证自动保存只改变内部编号。
- 运行 TypeScript/Vite 生产构建。
