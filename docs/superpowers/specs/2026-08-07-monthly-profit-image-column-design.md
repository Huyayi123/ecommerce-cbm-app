# 月度利润图片列设计

## 目标

在“月度利润”页面的 SKU 汇总表最左侧增加图片列，帮助老板快速识别商品。

## 数据来源

- 图片使用同店铺 SKU 资料库中的 `imageUrl`。
- 月度利润计算生成 SKU 汇总明细时，将匹配到的 `imageUrl` 放入页面内存中的明细对象。
- 不新增数据库字段，不保存月度 SKU 明细。

## 页面展示

- 汇总表第一列标题为“图片”，后续依次为 SKU、产品名称等现有列。
- 图片使用现有 `sku-thumb` 缩略图样式，保持与其他 SKU 表格一致。
- 图片使用懒加载；链接为空或加载失败时显示 `-`。
- 展开的销售明细和退货明细不重复显示商品图片。

## 范围

- 不改变销售、退货或利润计算逻辑。
- 不改变 Supabase 表结构。
- Excel 导出保持现有文字数据，不嵌入图片。

## 验证

- 有图片的 SKU 正常显示缩略图。
- 无图片或图片加载失败时显示 `-`，且表格布局不变。
- TypeScript 与 Vite 生产构建通过。
