# 我的采购订单导出增加内部编号

## 目标

在“我的采购订单”下载的专用 Excel 中，在“厂家名”后、“SKU”前增加“内部编号”列，方便采购人员对应内部商品编码。

## 设计

- 主商品使用采购记录保存的 `internalCode`。
- 混装商品根据规范化 SKU 从当前 SKU 资料库匹配内部编号；没有匹配时留空。
- 仅调整“我的采购订单”专用导出，不改变采购订单池、采购/在途库存及其他导出格式的现有字段。
- 新列加入后同步后移总金额、总 CBM、重量及混装总数的公式列和合并列，并更新样式与列宽。

## 验证

- 普通采购订单导出的内部编号正确。
- 混装明细存在 SKU 资料时显示内部编号，缺失时为空。
- 总金额、总 CBM、总重量和混装总数公式仍位于正确列。
- TypeScript/Vite 生产构建通过。
