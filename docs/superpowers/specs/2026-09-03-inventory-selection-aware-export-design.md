# 采购 / 在途库存选中优先导出设计

## 背景

采购 / 在途库存页面已经支持跨分页勾选记录，但“导出 Excel”和“导出 CSV”始终导出当前筛选结果，无法只导出用户明确勾选的产品。

## 目标

- 有勾选记录时，Excel 和 CSV 只导出勾选记录。
- 没有勾选记录时，Excel 和 CSV 导出当前筛选结果。
- 保持现有筛选、分页、验货单和订单状态逻辑不变。

## 设计

页面生成统一的普通导出数据源：

```text
勾选记录数量 > 0 ? 全部勾选记录 : 当前筛选结果
```

具体规则：

- 勾选状态继续按采购记录 ID 保存，可以跨分页。
- 已勾选记录即使因切换筛选条件而暂时不可见，仍参与普通 Excel/CSV 导出。
- 完全没有勾选时，只导出当前筛选条件下的记录，不导出筛选范围之外的数据库历史。
- “导出 Excel”和“导出 CSV”使用完全相同的记录集合，仅文件格式不同。
- 有勾选时按钮显示“导出 Excel（已选 N）”和“导出 CSV（已选 N）”；无勾选时保持原文字。
- 普通导出后不清空勾选，也不修改记录状态。
- “导出验货单”继续仅允许导出勾选记录，并沿用导出后标记到货的现有业务逻辑。
- “导出本批次订货表”保持现有逻辑，不受普通导出选择规则影响。

## 空数据处理

- 有勾选时，按钮依据有效勾选记录数量启用。
- 无勾选时，按钮依据当前筛选结果数量启用。
- 如果勾选 ID 对应的记录已经被删除或不再属于在途库存，不纳入导出。

## 验证

1. 勾选两条记录时，Excel 和 CSV 均只收到这两条记录。
2. 跨分页勾选时，导出包含所有有效勾选记录。
3. 切换筛选后隐藏已勾选记录，导出仍包含该勾选记录。
4. 清空勾选后，导出恢复为当前筛选结果。
5. 普通导出后勾选集合和订单状态不变。
6. TypeScript 生产构建通过。
