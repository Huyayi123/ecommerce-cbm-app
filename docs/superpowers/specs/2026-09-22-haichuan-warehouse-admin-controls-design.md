# 海川仓库全选、数量修改与库存删除设计

## 背景

海川物流商在“仓库存货”选择装柜产品时，需要逐条勾选。管理员和所有者目前只能查看海川仓库库存，无法修正误录的采购总数量，也无法清理错误入仓的单条库存记录。

## 目标

1. 海川物流商可以一键选择或取消选择当前可装柜库存。
2. 管理员和所有者可以安全修正仓库记录的采购总数量。
3. 管理员和所有者可以在确认弹窗后删除尚未进入装柜流程的整条仓库记录。
4. 所有跨表修改通过 Supabase RPC 在单个数据库事务内完成。

## 物流商全部选择

- “仓库存货”表头的选择列增加“全部选择”复选框及文字提示。
- 操作范围为当前搜索结果。
- 仅选择剩余件数大于 0、没有冻结件数的记录。
- 混装记录作为一个仓库批次整体选择，并默认选择全部可用件数。
- 全部符合条件的可见记录已选中时，复选框显示选中；只选中部分时显示半选状态。
- 再次点击时取消当前搜索结果中的所有选择，不影响被搜索条件隐藏的选择。

## 修改采购总数量

### 权限与入口

- 只在管理员/所有者的“海川仓库库存”页面显示“修改数量”操作。
- 海川物流商不能修改采购总数量。
- 点击后打开小型确认弹窗，展示产品、原采购总数量、新采购总数量、已装柜数量、修改后的剩余数量和剩余 CBM。

### 计算规则

- 已装柜数量 = `initial_product_quantity - remaining_product_quantity`。
- 新剩余数量 = 新采购总数量 − 已装柜数量。
- 新采购总数量不得小于已装柜数量。
- `reserved_carton_count > 0` 或存在引用该仓库记录的审核中装柜批次时禁止修改。
- 新初始 CBM 按原始单位 CBM比例计算；新剩余 CBM按新剩余数量同比例计算。
- 普通产品同步调整产品明细中的主产品数量和总 CBM。
- 混装记录保持主产品与混装子产品的原有数量比例、混装组和箱组关系；明细数量按新总数量比例缩放，最后一项吸收四舍五入差额，确保明细数量合计等于新采购总数量。
- 箱数、每箱数量和尾箱数量不由本操作自动改写，页面继续显示原申报包装数据；若数量与包装不一致，保留现有包装差异提示。

### 数据库操作

新增仅管理员可调用的 RPC，在事务内锁定仓库记录并再次检查冻结和审核中状态，然后更新：

- `initial_product_quantity`
- `remaining_product_quantity`
- `initial_cbm`
- `remaining_cbm`
- `product_details`
- `has_packing_variance`
- `version`
- `updated_at`

并同步更新关联入仓记录中的采购总数量、申报总 CBM和产品明细快照。

## 删除仓库记录

### 权限与确认

- 只在管理员/所有者页面显示删除按钮。
- 点击后弹出确认窗口，显示产品名称、SKU，并提示混装记录会整组删除且操作不可恢复。
- 用户二次确认后才调用删除 RPC。

### 删除条件

只有同时满足以下条件才能删除：

- `remaining_product_quantity = initial_product_quantity`，即尚未装柜；
- `reserved_carton_count = 0`；
- 不存在引用该仓库记录的审核中或已通过装柜明细；
- 混装记录按整个仓库批次删除，不能删除单个子产品。

### 事务处理

RPC 在同一事务内：

1. 锁定并校验仓库记录。
2. 删除关联的海川仓库记录。
3. 删除对应的待入仓/已收货快照记录。
4. 将关联采购记录恢复为 `pending_purchase`、`pending`、未确认状态，使其回到“我的采购订单”供重新处理或删除。

任何一步失败则全部回滚。

## 页面刷新与错误处理

- 修改或删除成功后刷新海川数据和采购记录。
- RPC 返回业务错误时，弹窗保持打开并展示明确原因，例如“存在冻结件数”“数量低于已装柜数量”或“已有装柜历史，不能删除”。
- 网络错误不预先修改本地列表，避免界面与数据库不一致。

## 测试

- 全选只覆盖当前搜索结果中的可用记录。
- 全选和取消全选不影响搜索结果外的选择。
- 普通库存数量调整正确保留已装柜数量并重算剩余 CBM。
- 数量低于已装柜数量时拒绝修改。
- 冻结或审核中库存拒绝修改。
- 混装明细按比例调整且合计等于新总数量。
- 未装柜、未冻结库存可以整条删除并恢复采购记录。
- 已装柜、冻结或存在装柜历史的库存拒绝删除。
- 非管理员无法调用修改或删除 RPC。
- TypeScript、Vite 构建和海川业务测试通过。

## 验收标准

物流商可以一键勾选当前列表中所有可装柜库存。管理员/所有者可以通过确认弹窗修正安全状态下的采购总数量或删除未进入装柜流程的整条仓库记录，所有相关表保持一致，混装关系和已有装柜数据不会被破坏。
