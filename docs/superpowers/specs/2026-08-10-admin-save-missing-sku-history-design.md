# 管理员保存无 SKU 历史记录设计

## 目标

允许管理员和老板在“采购 / 海运在途库存”中修改并保存已有的无 SKU 历史记录。

## 规则

- 已有记录处于编辑状态时，管理员或老板可以在 SKU 为空的情况下保存修改。
- 新增采购记录仍然必须填写 SKU。
- buyer 等其他角色仍不能保存无 SKU 记录。
- 不自动生成临时 SKU，不修改历史记录的其他字段。

## 实现

- `PurchaseInventoryPage` 接收一个仅用于历史无 SKU 记录的布尔权限。
- `App` 仅在角色为 `admin` 或 `owner` 时开启该权限。
- 保存按钮与保存函数共用同一判断，防止只修改界面而留下绕过路径。

## 验证

- 管理员和老板可以保存已有无 SKU 记录。
- 管理员新增无 SKU 记录时按钮仍禁用。
- buyer 编辑无 SKU 记录时仍不能保存。
- 有 SKU 的现有新增和编辑流程保持不变。
- TypeScript 与 Vite 生产构建通过。
