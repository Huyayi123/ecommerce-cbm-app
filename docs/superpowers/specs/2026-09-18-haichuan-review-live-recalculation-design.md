# 海川审核最终数量实时联动设计

## 目标

管理员在“海川装柜审核”中修改“最终装柜件数”时，页面立即重新计算同一行的“最终装柜数量”和“最终 CBM”。自动计算完成后，管理员仍可手工微调最终数量或最终 CBM。

本次修改只影响海川装柜审核，不改变整柜、冠通、采购池、入仓确认或物流商提交装柜的现有流程。

## 计算来源

实时计算必须读取装柜项目关联的海川仓库存货批次，并使用以下当前数据：

- 当前剩余件数。
- 当前剩余产品数量。
- 当前剩余 CBM。
- 原申报整箱件数、每箱数量和尾箱数量。
- 是否存在包装件数差异。

不得只按照海川原申报的装柜数量进行二次比例换算，以免连续修改时产生累计取整误差。

## 联动规则

修改“最终装柜件数”后：

1. 将输入规范为非负整数，并且不得超过该库存批次当前剩余件数。
2. 调用海川现有的装柜建议计算规则，以仓库存货批次为基准重新计算产品数量和 CBM。
3. 同步更新当前审核草稿中的最终件数、最终数量和最终 CBM。
4. 页面立即显示新结果，无需失焦、刷新或重复点击。

计算继续遵守现有规则：

- 无包装差异时，按每箱数量和尾箱规则精确计算。
- 有包装差异且只装走部分件数时，按当前剩余数量和 CBM 的件数比例估算，产品数量向下取整。
- 装走全部剩余件数时，直接使用全部剩余产品数量和剩余 CBM，消除累计取整误差。
- 输入 0 时，最终数量和最终 CBM 同步为 0。

例如库存剩余 8 件、105 个产品、0.105 CBM，且存在包装差异：最终件数从 6 改为 5 后，最终数量实时变为 65，最终 CBM 实时变为 0.065625。

## 手工微调

自动联动后，“最终装柜数量”和“最终 CBM”继续保持可编辑。管理员可以在自动结果基础上手工修改。

- 手工修改数量或 CBM 后，不反向修改最终件数。
- 只有管理员再次修改最终件数时，系统才重新执行自动计算，并覆盖此前对该行数量和 CBM 的手工微调。
- 备注、装柜日期及其他审核行互不影响。

## 实现边界

- 复用 `calculateHaichuanLoadingSuggestion`，不在页面中复制第二套计算公式。
- 通过 `warehouseLotId` 查找对应的 `HaichuanWarehouseLot`；找不到库存批次时保留当前审核草稿，并显示明确错误，不能静默写入错误结果。
- 后端审核 RPC 继续执行库存版本、状态及数量上限校验，前端实时联动不能替代后端校验。

## 验收

- 包装差异库存 8 件、105 个、0.105 CBM：最终件数改为 5，立即显示 65 和 0.065625。
- 同一记录改为装走全部 8 件，立即显示 105 和 0.105。
- 无包装差异记录按每箱数量及尾箱规则精确更新。
- 自动更新后可单独手工修改最终数量和最终 CBM。
- 手工微调后再次修改最终件数，数量和 CBM 按新件数重新计算。
- 输入超过剩余件数、负数或非整数时不能提交无效结果。
- 其他审核行以及整柜流程保持不变。
