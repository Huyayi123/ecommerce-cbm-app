# 海川导出按钮布局设计

## 目标

改善海川仓库管理导出按钮的位置与视觉一致性，将导出操作从表格上方移动到页面标题栏右侧，并置于“刷新”按钮左侧。

## 交互

- 标题栏右侧使用同一个紧凑操作组，按钮顺序为“导出 → 刷新”。
- 海川仓库库存页签显示“导出 Excel”，导出当前搜索结果；无数据时禁用。
- 海川装柜审核页签显示“导出当前批次”，导出当前选中的批次；未选择批次或批次无明细时禁用。
- 已装柜页签显示“导出 Excel”，导出全部已装柜记录；无数据时禁用。
- 物流商绑定页签不显示导出按钮，仅显示“刷新”。
- 海川物流工作台不显示该导出按钮。

## 实现范围

- 删除三个业务区域内原有的导出按钮。
- 在页面标题栏根据当前页签渲染对应导出按钮。
- 复用现有导出函数与按钮样式，不改变导出字段、数据范围、文件格式和异常提示。
- 为标题栏操作组增加最小必要的布局类，确保按钮横向排列且间距一致。

## 验证

- 三个目标页签的导出按钮均位于刷新按钮左侧。
- 切换页签时按钮文字、可用状态和导出动作正确更新。
- 物流商绑定和海川物流工作台不显示导出按钮。
- 原表格上方不再残留导出按钮或多余空白。
- 项目构建通过。
