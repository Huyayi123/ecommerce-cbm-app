# 采购订单池固定列设计

## 背景

采购订单池字段较多，表格需要横向滚动。滚动到数量、金额和状态等右侧字段时，产品身份信息会离开视口，难以判断当前行对应的商品。采购 / 在途库存已经采用固定列方式解决同类问题。

## 目标

采购订单池横向滚动时，连续固定以下九列：

1. 图片
2. 厂家名
3. 内部编号
4. SKU
5. 产品名称
6. 英文名称
7. 店铺
8. 采购人
9. 装柜日期

“内部编号”虽然不在最初点名的字段中，但它位于厂家名和 SKU 之间。将图片到装柜日期作为连续固定区域，可以避免非固定列从固定列之间穿过或被覆盖。

## 实现设计

- 复用采购 / 在途库存的 CSS `position: sticky` 实现方式，为九列分别设置明确宽度和累计 `left` 偏移。
- 给采购订单池表头和对应数据单元格增加语义明确的固定列类名。
- 固定表头的层级高于固定数据单元格；普通表头仍保持现有纵向固定行为。
- 在最后一列“装柜日期”右侧添加轻微分隔阴影，标示固定区域边界。
- 固定单元格使用不透明背景，防止横向滚动的内容透出。
- 主行、混装子行和备注高亮行分别沿用当前背景色；固定列不改变原有行状态表现。
- 对较长的厂家名、产品名称和英文名称采用现有的单行截断表现，避免固定区域无限增宽。

## 范围限制

- 不改变采购订单池字段顺序、字段内容、数据读写或编辑行为。
- 不改变采购 / 在途库存及其他页面。
- 不增加新的用户设置或响应式布局模式。

## 验证

- 横向滚动后，九个固定列持续可见且不发生重叠、间隙或内容透出。
- 表头纵向滚动时继续固定，并与九个横向固定列正确叠放。
- 普通主行、带备注高亮行和混装子行的背景色均正确。
- 固定区域之后的“计划采购数量”等字段可以正常滚动。
- 项目构建通过，且没有新增 TypeScript 或 CSS 构建错误。
