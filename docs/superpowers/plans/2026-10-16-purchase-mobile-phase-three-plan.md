# 采购 / 在途库存移动端适配实施计划

## 1. 业务边界

- 只调整手机端筛选区、新增/编辑容器及响应式布局。
- 复用现有筛选、分页、导入导出、选择、到货、保存和删除逻辑。
- 不修改库存口径、金额与 CBM 计算、权限、接口、数据库或桌面表格。

## 2. 卡片摘要

- 显示状态、产品、SKU、内部编码、批次、采购数量、件数、金额和 CBM。
- 卡片日期摘要显示装柜日期，未填写时显示“未填写”；批次信息继续保留在详情及原有功能中。
- 混装记录显示醒目标识，子商品摘要继续保留。
- 可编辑角色进入全屏编辑；只读角色进入全屏详情。

## 3. 新增与编辑

- 手机默认隐藏现有长表单，提供独立新增入口。
- “新增记录”入口名称保持不变，表单标题保持“新增在途库存”或“编辑在途库存”。
- 新增和编辑继续共享现有草稿与保存函数。
- 手机表单使用固定标题栏和底部操作栏，打开时隐藏全局底部导航。
- 字段按基础信息、数量与箱规、价格与体积、在途信息、物流补充、状态与备注的顺序排列，并保留全部在途库存字段。
- 底部依次放置主操作、清空和取消按钮，沿用“我的采购订单”的尺寸与居中方式。
- 保存成功、取消或返回后恢复列表；失败时保留表单内容。

## 4. 移动端筛选

- 新增移动端专用紧凑筛选区，默认只显示状态、搜索和“更多筛选”。
- 状态直接更新现有 `filters.status`；搜索沿用现有草稿值和回车/按钮提交逻辑。
- “更多筛选”打开独立面板，保留采购月份、厂家、店铺、采购人、批次、装货方式和采购日期范围。
- 面板使用临时筛选草稿：应用时写回现有筛选状态，取消时丢弃草稿，重置时恢复页面默认筛选值。
- 桌面端继续渲染原有完整筛选网格与搜索栏；通过响应式样式隔离两套展示，不复制筛选业务逻辑。

## 5. 文件与实现步骤

1. 在 `src/pages/PurchaseInventoryPage.tsx` 增加移动端筛选面板状态、打开/应用/重置/取消处理，以及紧凑筛选结构。
2. 在同一页面按确认顺序调整在途库存表单字段，并保留现有绑定、校验和保存函数。
3. 在 `src/styles.css` 增加移动端筛选栏、筛选面板和表单分组样式；桌面断点下隐藏新增移动端结构。
4. 检查页面关闭、保存成功及权限变化时的移动端临时状态清理。

## 6. 验证

- 运行生产构建与全部现有业务测试。
- 验证状态和搜索、更多筛选的应用/重置/取消，以及新增、编辑、删除、批量到货、验货单、分页和导出行为。
- 验证“新增记录”入口文案不变、表单全部字段仍可访问、按钮居中且不被底部导航遮挡。
- 检查编辑与删除权限、只读详情、手机横向溢出及桌面端回归。

## 7. 回滚边界

- 移动端新筛选结构和样式可以独立删除，原有桌面筛选和 `filters` 数据结构仍可直接工作。
- 表单只调整 JSX 排列和移动端样式；不迁移数据、不修改保存函数，因此可通过恢复字段顺序回滚。
