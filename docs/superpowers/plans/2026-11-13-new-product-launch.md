# New Product Launch 一期开发计划

依据 [一期设计](../specs/2026-11-13-new-product-launch-design.md) 执行。

## 1. 中国端数据层

- 新增 Supabase 迁移，建立新品记录和操作历史。SKU 使用纯数字文本，联合店铺 ID 唯一。唛头允许为空。确认状态与确认字段使用数据库约束。
- 在数据库事务中处理确认、SKU 纠错和撤销。并发确认只写入一次。同版本重试返回原确认。纠错和撤销记录操作者、原因和时间，并更新版本。
- 验证同 SKU 跨店铺可录入、同店重复被拒绝、前导零保留，以及旧版本请求在撤销或核对资料修改后被拒绝。

## 2. 中国端页面和接口

- 接入现有导航、登录和店铺资料，新增列表和录入表单。配置私有主图存储。提供录入人和管理员的纠错入口。
- 提供分页查询和到货确认接口，明确响应字段、版本冲突和重试行为。向 BMS 团队交付请求和响应示例及联调凭据配置方式。
- 验证唛头留空可保存，查询返回主图地址，非授权请求被拒绝，确认完成后中国页面刷新可见。

## 3. BMS 接入

- BMS 后端使用服务凭据访问接口，从员工会话取得确认人。页面展示唛头，空值显示「未填写」。用指定测试账号联调。
- 验证确认超时后可重新查询，重复提交保留首次确认，版本冲突时刷新资料并重新核对。

## 4. 试运行和上线

- 使用同一 SKU 的两家店铺记录走完录入、查看、确认、撤销和重新确认，核对独立状态和完整操作历史。
- 确定 BMS 正式确认权限后开放生产确认。
